# CartoonZombies — editor (leveranse)

**Beholdt for eksamen:** ett editor-vindu som **ikke** er med i `.exe`, men hjelper med tuning i Unity.

## CartoonZombies → Settings

- **Meny:** `CartoonZombies` → `Settings`
- **Kilde:** `Assets/Scripts/Editor/GameSettingsWindow.cs`
- **Innhold:** faner for **Audio**, **Waves** (WaveData), **Player**-prefab, **Zombie**-prefab, **Cheat (dev)**-innstillinger. Endringer skrives til ScriptableObjects / prefabs der det er naturlig.

Øvrige tidligere menyvalg (Fix / Repair / Scenes / …) er **fjernet** fra prosjektet for å redusere støy og størrelse før innlevering. Gjør NavMesh, Build Settings og scene-arbeid **manuelt** i Unity (se `EKSAMEN_OPPSTART.md`).
